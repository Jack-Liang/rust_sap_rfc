terminal 连通测试 

curl -X POST {{BASE_URL}}/api/rfc \
  -H "Content-Type: application/json" \
  -d '{"func_name":"STFC_CONNECTION","inputs":{"REQUTEXT":"hi"},"string_outputs":{"ECHOTEXT":255,"RESPTEXT":255}}'

返回 ECHOTEXT 回显输入、RESPTEXT 带 SAP 系统信息

面向 AI 的元数据 API

  • GET /api/functions/{name} 查函数接口
  • POST /api/functions/search 搜索函数模块
  • GET /api/functions/{name}/doc 查函数文档
  • GET /api/ddic/type/{name} 查 DDIC 结构
  • GET /api/ddic/field/{table}/{field} 查字段语义

通用调用

POST /api/rfc 通用 RFC 调用

支持请求体 timeout_secs per-request 覆盖超时
